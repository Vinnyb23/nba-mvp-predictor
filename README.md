# NBA MVP Predictor

A Python machine-learning project that predicts and ranks NBA MVP candidates using historical NBA player statistics, team performance, and MVP voting data.

## Project goals
- Build a reproducible historical NBA MVP voting dataset.
- Engineer player-performance and team-success features.
- Train and compare baseline and machine-learning ranking models.
- Evaluate predictions using season-based holdout testing.
- Present results in an interactive Streamlit application.

## Tech stack
Python, pandas, scikit-learn, XGBoost, Plotly, Streamlit, and GitHub.

## Project status
Phase 1: Repository setup and data audit.

## Disclaimer
This project is an educational analytics exercise. It does not claim to predict official award outcomes with certainty.
